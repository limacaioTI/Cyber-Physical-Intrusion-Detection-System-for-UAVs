# Datasets

Links para download e documentação. **Não versionar** arquivos brutos grandes: nesta pasta, `data/.gitignore` ignora `*.csv`, `*.npy` e `*.pcap`. Mantenha só instruções ou amostras anonimizadas se precisar versionar algo pequeno (e use exceções no `.gitignore` se for o caso).

## UAV-Attack / dataset ciber-físico (Hassler et al.)

Registros de voo sob operação normal e sob ataques (DoS, replay, injeção de dados falsos, etc.), em formato tabular para IDS baseado em ML.

- [Cyber-Physical Dataset for UAVs Under Normal Operations and Cyber-Attacks — IEEE DataPort](https://ieee-dataport.org/documents/cyber-physical-dataset-uavs-under-normal-operations-and-cyber-attacks) [GitHub](https://github.com/uamughal/UAVs-Dataset-Under-Normal-and-Cyberattacks/blob/main/Dataset_T-ITS.csv)
- [UAV Attack Dataset — IEEE DataPort (acesso aberto)](https://www.ieee-dataport.org/open-access/uav-attack-dataset)

## MAVLink — sequências de IDs de mensagem

Sequências de IDs de mensagens MAVLink (inclui amostras `.npy` e, em geral, PCAPs associados) para análise de comportamento de rede e IDS.

- [MAVLink Message ID Sequence Dataset — IEEE DataPort](https://ieee-dataport.org/documents/mavlink-message-id-sequence-dataset)
- [Espelho / página do laboratório (HCRL)](http://ocslab.hksecurity.net/Datasets/mavlink-message-id-sequence-dataset)

> Contas **IEEE DataPort** podem ser necessárias para download; leia a licença de cada dataset antes de publicar resultados derivados.
